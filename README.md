# DojoSoft

Full-stack learning projects with Django and React.

## Projects

### django
- **djangocrud** - Django CRUD application with REST API
- Database: SQLite

### react
- **react_todo** - Todo app built with React 18 and Vite

## Tech Stack

- Python, Django
- JavaScript, React 18, Vite
- ESLint, SWC

## Setup

```bash
# Django
cd django
python manage.py migrate
python manage.py runserver

# React Todo
cd react/react_todo
npm install
npm run dev
```

## Usage

- Django API runs at `http://127.0.0.1:8000/`
- React dev server at `http://localhost:5173/`
